Guardar notas no GitHub

1) Crie um repositório privado só para os dados (ex.: nfse-dados).
2) Em GitHub → Settings → Developer settings → Fine-grained tokens, crie um token apenas para esse repositório, com Contents: Read and write.
3) Crie uma senha. O token é criptografado com ela (AES-256) e só abre neste aparelho, depois de você digitar a senha. Se esquecer a senha, é só gerar outro token (não há recuperação).
